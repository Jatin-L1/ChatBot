AI Chatbot
This chatbot is designed to integrate multiple AI models seamlessly. Just add your API keys, and the chatbot will automatically connect and start working. No extra setup is needed!

How It Works:
Add Your API Key – Simply enter the API key of the AI model you want to use.
Automatic Integration – The chatbot will detect and connect to the AI without extra configuration.
Start Chatting – Once the API key is added, you can instantly interact with the AI.
This makes it easy to switch between different AI models and use their power in one unified chatbot!
